# 私人邮件助理接入与验收清单

当前只交付设计和 3 个 Skill。以下为**未来实施的未完成清单**，不是已有连接结果，按用户 [完整方案](../../docs/email/workbuddy_email_assistant_implementation_plan.md) M0–M6 推进。先用合成邮件/模拟邮箱和 Mock，不输入真实密码或 Token 到聊天。

## M0：接入信息与本人偏好

- [ ] IT 确认邮箱厂商、版本、云/自建、真实服务器、端口、TLS/企业 CA、代理/出口白名单；不猜 hostname，不关闭证书校验。
- [ ] 确认 IMAP、OAuth/专用授权码/密码和客户端审批；不可用评估正式 API，不擅自网页抓取或全邮箱转发。
- [ ] 明确试点本人、账户/文件夹（INBOX 及真实自动分流路径）、历史回填范围；已发送文件夹独立批准。
- [ ] 正文缓存、模型输入输出、摘要、日志、备份的保留/删除/撤销策略；未批不持久化真实正文。
- [ ] 企业批准模型端点、数据区域、日志政策、正文能否外发与独立后台 API 费用。
- [ ] 本人通知通道授权：源方案候选企微自建应用，确认映射、可见范围、权限、出口、限流、锁屏披露；不能默认群 Webhook 或普通会话回复。
- [ ] 本人确认项目/联系人、必须提醒、误报漏报门槛、业务时区、每日时间、周末、免打扰；P0 夜间与升级他人另批。
- [ ] 明确管理员、规则负责人、故障接收人；填写 [中立连接资料](connector-profile.example.json) 非秘密项。
- [ ] 确认测试数据授权与试点范围。退出：批准范围内可测试邮箱和本人通知。

## M1：只读同步与解析

- [ ] 固定批准技术版本/锁文件，建立 PostgreSQL 状态/任务/租约迁移，秘密只用引用。
- [ ] TLS/认证后列真实文件夹，只读会话记录 UIDVALIDITY 和 UIDNEXT。
- [ ] 实时新增先建基线，回填独立低优先级；发现记录/任务先落库，再推进扫描范围游标。
- [ ] 不用序号、UNSEEN 或标题时间做增量，正确处理 UID 空范围/缺口。
- [ ] 测自动分流、断线/重启、UIDVALIDITY 改变、重复/缺失 Message-ID、迟到及已删邮件。
- [ ] MailParser 流式/受控解析，附件首期元数据，HTML 不执行脚本/加载网络图片。
- [ ] 独立客户端对照已读、标志、位置，证明只读；记录检查时间和积压。
- [ ] 退出：测试邮件正确获取/显式异常，源邮箱无写入。

## M2：研判与证据

- [ ] 版本化 mail-policy、Schema 与提示，无工具模型提取，后台验证证据/授权 ID。
- [ ] 可表示线程可靠性、历史引用、期限原文/时区/null、附件未读和已发送缺失。
- [ ] 本人确认 P0/P1/P2/强制规则，needs_review 独立于优先级。
- [ ] 分开校准/验收集，评估待办/责任/期限/证据、P0 精确/召回、重复提醒；无 P0 不报 100% 召回。
- [ ] 模型超时/非法输出/虚构证据有界重试和可见降级，不丢强制提醒候选。
- [ ] 退出：达到本人约定门槛，关键结论可定位证据。

## M3：唯一后台调度与本人通知

- [ ] 唯一正式邮件调度，同日期/时区/计划唯一任务，关闭 WorkBuddy 不停止后台。
- [ ] 快照含新内容、迟到、旧事项新回复和未关闭待办，保存不可变版本/coverage_manifest。
- [ ] 四段简报：本人待处理、项目变化、等待对方、其他知会/覆盖限制；未分析/未呈现不跳过。
- [ ] Outbox 事务登记，通知 Worker 固定本人，验证 accepted/unknown/永久失败和有界重试。
- [ ] 重启、双触发、超时、停机、数据不完整时无重复/遗漏且状态可见。
- [ ] 认证确认页区分看到/处理，GET 不写；批准独立 IT 故障通道。
- [ ] 退出：Mock/批准通道重启与失败测试通过，真实自动业务推送仍按后续阶段批准。

## M4：WorkBuddy 只读 MCP 与三 Skill

- [ ] 实际版本核对 HTTPS/stdio、协议、认证/令牌注入，生成无密钥配置；MCP Token 非邮箱密码。
- [ ] 服务端令牌绑本人，只读角色和返回限制；无写邮箱或任意 SQL/URL/shell。
- [ ] 工具发现/七工具认证查询、过期/撤销、越权 ID、长正文、停机和注入测试。
- [ ] 安装 3 Skill 与同批准 policy，查阅/解释/覆盖可见，不能重复调度或发送。
- [ ] 实测邮件专家隔离公开搜索/智慧芽/任意文件/发送，不能靠提示词或 UI 隐藏。
- [ ] 关闭 WorkBuddy 发批准测试邮件，后台和通知仍运行；工具发现不等于全链通过。
- [ ] 退出：可查询解释，不能越权、写邮箱或外发私人数据。

## M5：获准真实数据影子对照

- [ ] 真实读取、模型处理、缓存分别获批；默认不自动推送业务提醒。
- [ ] 本人/授权人员对照事实、待办、期限、强制规则、误报漏报、覆盖和打扰。
- [ ] 私人邮件与公开每日资讯分别管理正文、凭据、缓存、任务和策略。
- [ ] 退出：本人确认规则与打扰程度，保留独立对照结果。

## M6：有条件正式启用

- [ ] 本人与 IT 验收后分级启用，夜间/升级按各自授权。
- [ ] 固定版本，交代码/锁文件/迁移/无密钥配置/7 工具/3 Skill/政策/测试联调报告。
- [ ] 独立监测文件夹新鲜度、积压、证据失败、unknown/失败通知及简报覆盖，不只检测进程。
- [ ] 演练恢复、轮换、回退、撤销邮箱/MCP 与批准缓存/备份删除，明确维护责任。
- [ ] 退出：安全可靠性、本人与 IT 验收、回退撤销路径通过，才声明正式启用。

功能 F01–F20、安全 S01–S12 和待协商指标见原方案第 16 章。平台接受不等于阅读；轮询周期不等于送达 SLA；不能恢复在观察前已被源端删除的邮件。
