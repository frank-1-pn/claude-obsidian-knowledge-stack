# 智慧芽 / Patsnap 管线 MCP：现场接入设计

状态：**待现场接入，不是已连接功能**。本次只说明连接与验收方法，不写入生效 MCP 配置、不访问付费数据或要求在聊天提供密钥。核查日期：2026-10-09。

## 用途与范围

为已经过 brainstorming 澄清的管线问题补充专业资产检索、详情和里程碑。官方国际平台的 [Drug & Asset MCP](https://open.patsnap.com/marketplace/mcp-servers/drug-asset) 列出 `drug_search`、`drug_fetch`、`drug_milestone_fetch` 三种工具。搜索可按药物、靶点、适应症、机构、药物类型、阶段和日期筛选；具体字段和配额须以客户实际订购服务的 schema 为准。

`highest_phase` 是历史/全球最高研发阶段，`dev_status` 是当前发展状态，不能混用。地区过滤、作用机制、资产别名、阶段更新日期、来源 ID 与查询时间都应在结果表保留。专业数据库记录仍需核对其覆盖范围和更新日期，不能视为正式医学/投资结论。

中国平台的 [MCP 快速开始](https://open.zhihuiya.com/devportal/guides/mcp-quickstart) 介绍 MCP Key 与 Bearer header；国际 Drug & Asset 页面展示的 endpoint 和鉴权形态不同。两者不能机械替换域名，也不假设国内通用专利 MCP 自动提供药物资产工具。

## 现场确认与连接

1. 确认中国/国际平台、企业订购的生命科学服务、许可用户、数据区域、可传查询内容、费用/额度与 IT 网络要求。
2. 从客户控制台复制实际服务配置，不将密钥写入仓库、笔记、截图或聊天。优先使用客户支持的凭证变量/安全存储；不要打印带密钥的 URL。
3. 使用 WorkBuddy 自定义连接器的实际支持方式配置对应 MCP。初次握手、认证和 `tools/list` 后核对工具名、schema 与权限。
4. 跑一个已知公开资产查询，读取详情/里程碑，核对分页、空结果、别名、最高阶段和当前状态；取得结构化响应与来源可追溯证据。
5. 记录更新日期、配额/费用、权限拒绝与服务故障的处理；无结果不等于资产不存在，覆盖不足如实列出。

## 输入与产物契约

输入是总监批准的调研范围和可对外检索的术语。输出为带来源 ID/URL、检索日期和版本的资产表、里程碑和证据审查；原始响应按企业数据条款在获准位置归档。私人邮箱或内部项目资料不得自动发送到智慧芽。

尚未连接时助手应说“智慧芽未接入”，并指出专业覆盖缺口。可以按用户选择使用公开来源或合成示例，但不能把它们标为智慧芽返回结果。

## 验收

真实 WorkBuddy 中的握手、工具发现、鉴权查询、详情读回、分页和错误/撤销测试都有结果；至少一条公开已知记录独立核对；费用与数据范围按客户权限确认。本轮不执行这些连接用例。
