# 合成数据说明

`efficacy.csv` 与 `pk.csv` 均是本项目为复刻演示手工构造的公开合成数字，没有来自患者、真实动物、企业实验或数据库。没有随机生成步骤，因此不需要随机种子。

- efficacy：vehicle/low/high 每组 8 个独立虚拟动物，每个只有一次预设终点。体积单位 mm³；体重变化单位百分比。数据不是基线或纵向记录，不计算TGI或重复测量模型。动物分组是合成设计声明，非真实随机化的证明。
- PK：另一个模拟队列的 3 个对象，单位 h 与 mg/L；说明用给药量 0.125 mg，仅用于暴露计算的单位演示。PK01 为基准曲线，PK02/03 分别乘 0.9/1.1。8、12、24h 三个末点来自半衰期4h的指数衰减真值，供独立解析检查。输入不含 BLQ 或缺失。
- 两个 CSV 的动物 ID 没有关联，不能把终点均值和 PK 结果合成暴露–反应关系。任何显著性、效应或耐受性观察只属于这组编造数字。

替换为真实研究数据之前必须重新定义设计、主要终点、重复测量、批次与笼位、缺失/BLQ约定、采血实际时间、给药与单位、分析人和复核人；当前示例不承担真实研究结论或方法认证。
