# 规则入口

完整规则以 config/vault-agents.template.md 为准，初始化后放在 vault 根 AGENTS.md；skills 承载任务流程。本页只提供导航，不维护第二份规则。

- 一份来源一篇笔记；源正文未经“整理这份”不改。
- 原料先归档，笔记含 100–200 字检索摘要、raw_path 和真实 provenance。
- 微信学习笔记保留阅读顺序；AI 解释就地标注，外部事实附来源；版权边界保持明确。
- 图片按需，附件放根 `_attachments/`；不强凑讲解和图片数量。
- 唯一集成人逐篇更新 graph/index、log、hot/latest，校验后最后写 manifest。
- 用户明确“同步”才定向 commit/push；workers 无共享元数据和 Git 权限。

参考 setup/00-workbuddy.md、ARCHITECTURE.md 及 skills/wiki-ingest/SKILL.md。
